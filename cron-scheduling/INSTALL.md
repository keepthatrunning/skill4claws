## 🔧 使用方式

### 对于用户
1. 在 HEARTBEAT.md 中添加/修改定时任务
2. 设置触发条件和优先级
3. 系统会在心跳时自动检查并执行

### 对于 Agent
1. 收到心跳消息时读取 HEARTBEAT.md
2. 按优先级顺序检查任务条件
3. 执行任务或返回 HEARTBEAT_OK
