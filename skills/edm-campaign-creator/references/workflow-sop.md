### Send Schedule Best Practices

**B2B Timing**
- Best: Tuesday/Thursday 10:00 AM
- Avoid: Monday morning, Friday

**B2C Timing**
- Best: Saturday 10:00 AM, Weekday 7:00-9:00 PM
- Avoid: Commute hours

**Ramadan Special**
- Best: After Iftar 9:00-11:00 PM
- Weekend mornings 10:00 AM-12:00 PM

### Audience Segmentation

**B2B Segments**
- By Industry: Hotels, Restaurants, Developers, Designers
- By Size: Enterprise, Mid-market, Small business
- By Value: High-value customers, New prospects
- By Behavior: Active, Dormant, At-risk

**B2C Segments**
- By Property: Villa owners, Apartment dwellers
- By Life Stage: Newlyweds, Families, Empty nesters
- By Value: VIP, Regular, Budget-conscious
- By Behavior: Frequent buyers, Window shoppers

## Phase 3: Content Creation

### Subject Line Formula

**Data-Driven**
- "[Number]% [Result] — [Benefit]"
- Example: "687% Sales Surge — See What's Trending"

**Emotional**
- "[Benefit] — [Timeframe]"
- Example: "Transform Your Garden This Ramadan"

**Urgency**
- "[Timeframe] — [Consequence]"
- Example: "48 Hours Left — Prices Increase Tomorrow"

### Email Copy Structure (AIDA)

**Attention**
- Compelling subject line
- Strong preview text
- Eye-catching hero image

**Interest**
- Relatable problem statement
- Customer story/case study
- Social proof (data/reviews)

**Desire**
- Product benefits (not features)
- Before/after transformation
- Exclusive offer/promotion

**Action**
- Clear CTA button
- Urgency element (deadline/stock)
- Multiple touchpoints

### Content Deliverables Checklist
- [ ] 3-5 subject line variants
- [ ] Preview text (50-80 characters)
- [ ] Headline and subheadline
- [ ] Opening paragraph
- [ ] Body content (2-3 sections)
- [ ] Customer story/testimonial
- [ ] Product descriptions (3-4 items)
- [ ] Primary CTA text
- [ ] Secondary CTA text
- [ ] Closing statement
- [ ] SMS copy (160 chars max)
- [ ] Push notification copy
- [ ] Social media post copy

## Phase 5: HTML & Preview Creation

### HTML Generation Steps

1. **Load Boilerplate**
   - Use: assets/email-boilerplate.html
   - Customize: Brand colors, fonts

2. **Build Structure**
   - Header with logo
   - Hero section with image
   - Content blocks
   - Product cards
   - CTA buttons
   - Footer

3. **Add Functionality**
   - UTM parameters on all links
   - Personalization variables [First Name]
   - Responsive breakpoints
   - Dark mode support

4. **Take Screenshot**
   - Use browser tool
   - Full page capture
   - Save as .jpg/.png

5. **Create Feishu Document**
   - Insert screenshot
   - Add structure explanation
   - Document design specs
   - Add technical details
   - Include pre-send checklist

### HTML Technical Requirements

**Email Client Compatibility**
- Gmail (web, iOS, Android)
- Outlook (desktop, web)
- Apple Mail (Mac, iOS)
- Yahoo Mail
- Samsung Mail

**Responsive Design**
- Desktop: 600px width
- Mobile: 100% width, single column
- Font scaling: 14px minimum on mobile

**Code Standards**
- Table-based layout (not CSS flex/grid)
- Inline CSS only
- Alt text on all images
- Web-safe fonts only

## Phase 7: Execution

### Send Day Preparation

**2 Hours Before**
- [ ] Final email test sent
- [ ] All links verified
- [ ] Team notified
- [ ] Monitoring dashboard ready

- [ ] Website load test
- [ ] Inventory synced
- [ ] Customer service briefed
- [ ] Emergency contacts available

**Send Moment**
- [ ] Monitor initial open rate (first 15 min)

|------|--------|
